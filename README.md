# Animates Dev

Локальный playground для установленного **Animates 1.0.14 (63)**.

После сборки запуск: `/Applications/Animates Dev.app`. Скрипт также создаёт локальную ссылку `Animates Dev.app` в папке проекта.

Используется оригинальный **Unity 6000.3.18f1 / IL2CPP / Metal**: его сцены, модели, шейдеры, материалы, свет, физика и анимации. Новая часть — панель AppKit, которая вызывает зарегистрированные самим Unity команды C ABI и методы исходного IL2CPP через runtime API. Установленный `/Applications/Animates.app` не изменяется.

## Управление

- Все контролы находятся в одной панели с вкладками **Эффекты, Образ, Движения, Мимика, Речь, Сцена**. Переключатель персонажа всегда сверху; дополнительные окна управления не открываются.
- Выбор всех семи сцен оригинального каталога: **Yuki, Nixie, Bot, Raccoon, Jareth, Ani, Mika**.
- Yuki и Nixie поставляются внутри оригинального приложения. Остальные сцены загружаются штатным Unity Addressables с `assets.animates.ai` и сохраняются в `~/Library/Caches/local.animates.playground`. При первом запуске на другом компьютере или после очистки кэша нужен интернет.
- Панель показывает только действия текущей сцены. Число исходных ID эффектов, включая команды остановки: Yuki — 21, Nixie — 4, Bot — 13, Raccoon — 8, Jareth — 4, Ani — 11, Mika — 10. Дополнительные эмоции показаны под исходными ID, удобными для отладки.
- Повторное нажатие на длительное действие отправляет соответствующую команду `stop_…`. «Остановить» выключает длительные действия и прерывает текущую генерацию.
- 6 оригинальных камер. Стартовый вид — **3 · SPIPCamera**, окружение — **1 · TimeOfDay**. Последний выбор сохраняется. Камеры для overlay могут скрывать окружение — это поведение оригинального движка.
- Касания, движение курсора и физика работают в окне Unity. Нативные состояния тела, лица и эффектов отображаются в панели.
- «Непрозрачность окна» управляет штатным `SetBackgroundAlpha`, а не яркостью текстуры комнаты.
- «Полный лог» открывает `~/Library/Logs/AnimatesDev/Unity.log`; там сохраняются исходные JSON-события `SceneVisualState`.
- **Образ:** все 9 ID костюмов и 5 причёсок из исходных сцен. Доступны 8 костюмов; праздничный костюм Mika проверен фактической сменой UUID. Второй костюм Nixie указан как недоступный: Unity этой версии возвращает `InvalidKeyException / No Location found` для `033ff1eaff1d73148b0bc4f5781de404`. Из отсутствующего ресурса нельзя собрать оригинальный костюм. Управление цветом волос включается только при наличии штатного контроллера цвета.
- **Движения:** исходные пути состояний Animator, поддерживаемые текущим персонажем параметры, скорость танца и сброс. Перед прямым запуском состояние проверяется через `Animator.HasState`; параметры одновременно могут влиять на переходы Animator.
- **Мимика:** каналы лица из runtime `blendShapeMapping`, привязанные к оригинальному 52-канальному анимационному буферу. Ползунки запускают выражение на 5 секунд; быстрые тесты комбинируют каналы улыбки, моргания и открытия рта. «Сброс» возвращает автоматическую мимику. Это ручные тесты каналов модели, а не дополнительные пресеты эмоций из поставки. На Ani проверены реальные деформации рта и улыбки; другие персонажи получают собственный список поддерживаемых каналов.
- **Речь:** локальный аудиофайл до 60 секунд преобразуется в mono float / 24 kHz и поступает в исходный inference для тела и лица. Проверена успешная генерация и завершение речи на Jareth. Шаги и стили по умолчанию взяты из кэшированного оригинального каталога API для каждого персонажа, а не из общих значений по умолчанию.
- **Сцена:** дистанция камеры, поворот персонажа и штатный просмотр буфера движений — открыть, выйти, воспроизвести, пауза, позиция. Это повтор внутри runtime, не экспорт видеозаписи.

Окно Unity сохраняет собственный `PlayerWindowView` на всю область содержимого. Панель прикреплена отдельным дочерним окном: это устраняет искажение пропорций, возникающее при сжатии Unity-view внутри более широкого окна.

## Сборка

```sh
git clone https://github.com/mishanaer/waifu.git
cd waifu
python3 build.py
python3 verify_original.py
```

Перед пересборкой нужно закрыть Animates Dev. Нужны установленный оригинальный Animates и инструменты Xcode (`clang`, `codesign`). Unity Editor не требуется. Сборка выполняется в `/Applications`, поскольку File Provider в Documents возвращает Finder-атрибуты, несовместимые с `codesign`. Используется локальная ad-hoc подпись.

`catalog.json` содержит эффекты, камеры, фоны, гардероб, состояния Animator и конфигурацию генерации всех семи сцен. `remote-bundles.json` фиксирует исходные URL, размеры и SHA-256 дополнительных bundles версии `20260908173050`. `src/UnityBridge.m` реализует главную панель и совместимый мост; `src/DevControls.m` — дополнительные вкладки и аудио; `src/DevRuntime.m` — вызовы оригинальных методов без фиксированных адресов памяти. `src/main.mm` запускает исходный UnityPlayer. `verification.json` подтверждает совпадение ресурсов и машинного кода движка с установленным оригиналом. `capabilities-verification.json` фиксирует проверенные механизмы и ограничения.

Это оболочка готового Unity runtime, а не восстановленный Unity Editor-проект: исходники C#, редактирование сцен в Editor и managed breakpoints отсутствуют. Сетевой чат и аккаунт оригинального SwiftUI-приложения не подключены; локальная генерация речи подключена. Новые эмоции произвольным числовым ID не отправляются: найденный `InterruptAndPlay` принимает индекс `CommandAnimations`, а его список в этих сценах пуст. Устаревшие `PlayCharacterSpeech`, `AppendAudio`, `AppendBlendShapesData`, `InterruptAndAppend` и `SetRBFActive` в этой сборке скомпилированы как пустые методы; работающие контролы на них не опираются. Нельзя обещать дополнительные скины или отдельные пресеты эмоций, ресурсов которых нет в исходной поставке.
